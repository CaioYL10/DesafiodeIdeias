# Desafio de Ideias — GR1 (SENAI)

Para contexto completo do projeto (fase atual, cronograma, próximos passos), veja [`CLAUDE.md`](CLAUDE.md).

- [`cronograma/`](cronograma) — cronograma da turma e status do GR1.

- [`entregas/`](entregas) — entregáveis finais (roteiro de entrevista atualizado, e futuros: CSD, persona, protótipos etc.).
