# Desafio de Ideias — GR1 (SENAI)

Repositório de trabalho do grupo GR1 no projeto "Desafio de Ideias" do SENAI (turma 2IEDS | 2026).

**Empresa atual:** [CTI](https://www.cti.com.br/) — provedor de internet corporativa, cloud e cibersegurança. **Problema:** a empresa não tem um setor de análise de qualidade. **Proposta:** um sistema que recebe e armazena avaliações dos serviços da CTI e gera relatórios para o time de gestão.

> Escopo anterior (Avanade do Brasil: jogo-aplicativo gamificado com RA e ChatBot) foi refatorado após reunião com a empresa. Detalhes em [`contexto/mudanca_de_escopo_cti.md`](contexto/mudanca_de_escopo_cti.md).

Para contexto completo do projeto (fase atual, cronograma, próximos passos), veja [`CLAUDE.md`](CLAUDE.md).

## Estrutura

- [`contexto/`](contexto) — mudança de escopo, dados da empresa e pontos em aberto.
- [`cronograma/`](cronograma) — cronograma da turma e status do GR1.
- [`fontes/`](fontes) — documentos originais do SENAI (roteiro-modelo, orientações gerais, cronograma, Plano de Ensino v2).
- [`entregas/`](entregas) — entregáveis (persona, roteiro, CSD, matriz, síntese; os da fase Avanade são histórico).
- [`scripts/`](scripts) — scripts que geram os `.docx` das entregas.
